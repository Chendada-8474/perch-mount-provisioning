# perch-mount-provisioning


The environment files that we need to setup manually:
1. `.env`: environment variables for [perch-mount-system](https://github.com/Chendada-8474/perch-mount-system)
2. `flask_secret`: flask secret for [perch-mount-system](https://github.com/Chendada-8474/perch-mount-system)
3. `jwt_secret`: jwt secret for [perch-mount-system](https://github.com/Chendada-8474/perch-mount-system)
4. `env.js`: basic environment variables for [perch-mount-frontend-2](https://github.com/Chendada-8474/perch-mount-frontend-2)
